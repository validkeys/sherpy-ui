# Sherpy onboarding — UI demo

This Storybook is the canonical demo surface for the Sherpy onboarding wireframes. It is a **pure UI demo** — no backend, no router, no state library. Components are dumb; stories pass concrete props.

The wireframe handoff lives in [`docs/plan/README.md`](https://github.com/validkeys/sherpy-ui/blob/main/docs/plan/README.md). The 13 frames (A–F gap analysis arc, G–H + I1–I5 interview arc) drive the structure here.

## Where to look

- **Frames / Gap analysis** — six frames (A → F): intake, gap generation, fill, merge, resolution.
- **Frames / Interview** — seven frames (G, H, I1 → I5): question/answer thread, ask-back aside, completion.
- **Components** — primitives by folder. Each folder ships component, story, fixtures, index.
- **Layouts / AppShell** — the live app frame (rail + header + stepper + main slot).

## Theme

Use the **Theme** toolbar in the top bar to flip every story between light and dark. Tokens come from `src/styles/tokens.css`. Per-story overrides exist for canonically-dark frames (e.g. completion).

## Conventions

- Storybook is the demo. `App.tsx` keeps a live route for `pnpm dev` smoke testing.
- Primitives are pure props-only — no `useState`, no `useEffect`, no fetches.
- Layout shells own grid/flex/scroll and accept named slots.
- Fixtures co-located per component folder (`fixtures.ts`).
- Tokens-only for color, spacing, radii, shadows. No hex literals outside `tokens.css`.
